# APIViaCEP

**Aluno:** Thierry Alves Mota Justino
**RA:** 0023636

Programa em Java que consulta um CEP na API pública ViaCEP usando `HttpClient` e mostra o retorno em JSON no console.

## Detalhes

- Classe principal: `APIViaCEP.atv.ConsumirCep`
- Endereço consultado: `https://viacep.com.br/ws/{cep}/json`
- O CEP deve ter 8 dígitos, sem traço

## Como executar

Abra a pasta `APIViaCEP` e rode a classe `ConsumirCep`. Não precisa de bibliotecas externas.
